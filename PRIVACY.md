# Privacy Policy

Effective date: 23 September 2026

Optimal Challenge is a skills-only Codex plugin published by Coding Baby Penguin. It contains instruction files that help Codex assess task complexity, reuse an applicable existing plan, and select focused workflows.

The plugin does not operate a server, create user accounts, independently collect personal data, or transmit data to Coding Baby Penguin. It does not include an MCP server or an external app connection.

When the plugin is used, the host product may process prompts, files, tool results, and account information under the host provider's own terms and privacy policy. Any specialist skill or connected service selected during a task is governed by its own permissions and policies.

Questions may be submitted through the repository's [GitHub Issues](https://github.com/Coding-Baby-Penguin/optimal-challenge-plugin/issues).
