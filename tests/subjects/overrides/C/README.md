# Optimal Challenge — evaluation arm C

This is an evaluation-only ablation built from the pinned v1.2 candidate source. It is not the public D release. The main `skills/optimal-challenge/SKILL.md` and its reviewed reference overlays govern host routing.

Arm C keeps the candidate economic delegation gate but omits the candidate premise/research-before-scale gate and logical teammate continuity. It uses fresh workers per assignment. Authority, explicit user controls, safety, permissions, host slots, budget/allocation reserves, observable done conditions and mandatory review remain binding. An explicit user research or verification request still binds.

The package includes standard-library runtime validation helpers. The source repository contains development tests and evaluation evidence tooling. Archive identity, installation and host behavior require separate read-back; this README does not establish comparative performance.
