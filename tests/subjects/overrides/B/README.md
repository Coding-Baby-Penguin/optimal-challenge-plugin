# Optimal Challenge — evaluation arm B

This is an evaluation-only ablation built from the pinned v1.2 candidate source. It is not the public D release. The main `skills/optimal-challenge/SKILL.md` and its reviewed reference overlays govern host routing.

Arm B omits the candidate premise/research-before-scale gate, economic delegation break-even gate, and logical teammate continuity. For at least two substantive independent workstreams, it delegates by default when authority, explicit user controls, safety, permissions, host slots, budget/allocation reserves, observable done conditions and mandatory review allow. Its configured numeric delegation margin is dormant for B host routing. Workers are fresh per assignment. An explicit user research or verification request still binds.

The package includes standard-library runtime validation helpers. The source repository contains development tests and evaluation evidence tooling. Archive identity, installation and host behavior require separate read-back; this README does not establish comparative performance.
